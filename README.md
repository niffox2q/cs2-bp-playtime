### Событие `playtime`

Модуль генерирует событие `playtime` каждые 60 игровых секунд. 

**Возвращаемые параметры:**
* `team` *(int)* — команда игрока:
  * `1` — Наблюдатель (Spec)
  * `2` — Террорист (T)
  * `3` — Контр-Террорист (CT)
* `mod` *(string)* — текущий режим игры (значение берется из конфига ядра).

#### Пример задания
**Цель:** Отыграть N время на Public-режимах за КТ.
* **Ивент:** `playtime`
* **Параметры:**
```json
{
  "mod": "Public",
  "team": 3
}
